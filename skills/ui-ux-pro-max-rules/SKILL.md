# ui-ux-pro-max-rules (발췌판)

- **본문**: 같은 폴더의 [`pro-rules.md`](pro-rules.md) — 원출처 `references/pro-rules.md` **원문 그대로**.
- **수치 기준표**: [`criteria.md`](criteria.md) — 원출처 `data/` CSV에서 뽑은 플랫폼별 수치와 안티패턴(원문 인용 + 출처 행 번호).
- **출처·검증·한계**: [`SOURCE.md`](SOURCE.md).

사용법: UI 코드를 넘기기 전에 `pro-rules.md`의 **Pre-Delivery Checklist**를 항목별로 대조하고, 수치 판정이 필요한 항목은 `criteria.md`의 기준값으로 확인합니다.
원출처의 검색 스크립트(`scripts/search.py`)와 데이터 3.8MB는 **이 발췌본에 포함하지 않았습니다**(아래 SOURCE.md 참조). 스타일·폰트·색 추천이 필요하면 원출처를 직접 클론해 씁니다.
